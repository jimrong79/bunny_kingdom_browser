# Landing illustration

`storybook-kingdom.webp` is an original AI-generated watercolor/gouache illustration created for this project's landing-page art exploration. It depicts a rabbit ruler, a river valley, a castle and a floating cloud kingdom. It is not taken from the commercial board game.

Generated with the built-in imagegen tool on 2026-09-09. The 1536 × 1024 image was converted to WebP at quality 88, retaining its dimensions. The game uses one 493,300-byte asset; no external image host or font service is required.

Art direction: warm ivory paper, sage woodland, forest-green cloak, antique gold, pale teal and subtle terracotta; watercolor with fine ink details. Keep the rabbit's two visible eyes, and use separate HTML for all page text and controls.

The Royal atlas option uses the game's existing code-drawn rabbits, cities and terrain. Its small decorative map is not a playable board or a substitute for the real map data.
