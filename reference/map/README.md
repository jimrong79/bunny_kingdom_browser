## Adding reference photos

Add a clear overhead photo of the original board. JPG, PNG, or a PDF scan is suitable.

Suggested filenames:

- `board-full.jpg`: the complete board, including row and column labels.
- `lava-closeup-01.jpg`: a close-up of any lava boundaries that are hard to distinguish in the full-board photo.

Keep the nearest coordinate labels visible in close-ups so they can be matched to the correct territories. Avoid glare over terrain symbols, starting cities, and shared edges.

The map transcription records each territory's terrain, starting cities, and lava as blocked connections between neighboring coordinates. The preview highlights the identified lava boundaries. Any unclear details in future reference photos should remain unverified until resolved.

Photos and other raw reference files in this folder stay local by default because Git ignores them. This README is the exception.
