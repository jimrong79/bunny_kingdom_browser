# Games for review

On the results screen, choose **Download game** and put the JSON file here.
After refreshing an older game, select **View last result** to reach that screen.

The export includes the complete saved state: seed, player count, bot difficulty,
hands observed during drafting, board, inventories, scoring, and activity log.
A seed recreates the initial deal; the saved game is needed to investigate the
actual decisions made in your match.

Windows folder: `C:\Users\jimro\workspaces\bunny_kingdom_browser\reference\games`

Exports in this folder stay local and are ignored by Git. The download does not
send anything to a server or alter the current game.
